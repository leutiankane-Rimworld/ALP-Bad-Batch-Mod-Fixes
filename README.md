# ALP-Bad-Batch-Mod-Fixes
Rewritten Bad Batch Mod  , made so i could share the fixes with current author so they can update their mod so it works better if they choose.
 just unzip these files and replace yours with them or use them to rewrite your own code , either way all i ask for is credit for the revamps on the mod page.
Changes

Each piece of gear has their own unique basedef (parent)

Vacuum Resistance from Odyssey as per marine armor.

Every piece is now stuffable with any metal installed in the game, so you can construct them for the original cost PLUS any metals installed in your game.

Thing Categories so that the armor will show up under BadBatch in storage shelves, creamtorium , smelter and such. 

Other than that i stuck with the balance you had set up before with their stats and such.

I deleted the Recipie defs as they were no longer needed .
